Política de privacidad

Última actualización: 27 de octubre de 2026

Qué hace IP Lookup

IP Lookup muestra la dirección IP pública desde la que se conecta tu navegador y te permite consultar otras direcciones IP y nombres de dominio. Para hacerlo, nuestras funciones serverless (alojadas en Vercel) reciben tu dirección IP como parte de cada solicitud web, exactamente como cualquier sitio web.

Lo que no guardamos

  • No registramos, guardamos ni vendemos las direcciones IP o los dominios que consultas, ni tu propia dirección IP. Se procesan en memoria solo durante la solicitud.
  • Se usa un contador temporal en memoria asociado a tu IP para limitar el abuso (60 solicitudes por minuto). Se descarta automáticamente y nunca se escribe en disco.
  • Tus consultas recientes, los datos del lote y tu preferencia de tema se guardan en el localStorage de tu navegador, solo en tu dispositivo. Puedes borrar el historial en cualquier momento con el botón "Borrar historial" o borrando los datos del sitio.
  • La información del navegador y del sistema operativo que se muestra en la página se calcula localmente en tu navegador y nunca se nos envía.

Terceros contactados en una consulta

  • Resolvedores DNS para el DNS inverso, la resolución de dominios y la revisión de listas de bloqueo DNS.
  • rdap.org y los registros regionales de Internet (ARIN, RIPE NCC, APNIC, LACNIC, AFRINIC) para obtener los datos públicos de registro de red de la dirección que consultas.
  • The Tor Project y abuse.ch para descargar sus listas públicas (no en cada consulta; las listas se guardan en caché).
  • Para las funciones Pro, tu clave de licencia se verifica con nuestro servicio de pagos (bm-payments.vercel.app). La clave nunca se comparte con terceros.

El proveedor de hosting Vercel puede conservar registros estándar de solicitudes (incluidas direcciones IP) por motivos de seguridad y operación, según su propia política de privacidad.

Precisión y ética

La geolocalización es aproximada (ciudad o región) y describe dónde está registrada o enrutada una red. Nunca identifica a una persona ni una dirección postal. Solo un proveedor de Internet puede vincular una dirección IP con un abonado, normalmente por orden judicial. Por favor, no uses esta herramienta para acosar, rastrear ni identificar a personas.

Fuentes de datos y atribución

  • Geolocalización de IP por DB-IP, con licencia CC BY 4.0.
  • Datos de ASN: RouteViews / DB-IP vía ip-location-db, CC BY 4.0.
  • Lista de salidas de Tor: The Tor Project. Lista de C2 de botnets: abuse.ch Feodo Tracker (CC0). Listas de bloqueo DNS: SpamCop, PSBL.

Cookies, analítica y publicidad

Si la analítica (Google Analytics) o la publicidad (Google AdSense) están habilitadas, esos servicios pueden instalar cookies y procesar datos como tu dirección IP e información del dispositivo para medir el uso y mostrar anuncios, incluidos anuncios personalizados cuando esté permitido. Puedes desactivar la publicidad personalizada en Configuración de anuncios de Google. Conoce cómo usa Google los datos en policies.google.com/technologies/partner-sites.

Pagos

Las compras Pro las procesa Mercado Pago. Nunca vemos los datos de tu tarjeta. Recibimos un ID de pago para emitir y validar tu clave de licencia.
